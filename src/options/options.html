🛡️ 拦截统计与隐私策略
统计规则拦截命中次数
当访问命中已配置的防护规则并自动删除历史时，是否累加记录拦截次数。关闭后进入极致无痕状态，不保存任何命中计数。
重置所有规则拦截计数
一键将当前所有防护规则的累计拦截次数清零，不影响规则本身的启用状态与拦截逻辑。
📦 规则备份与数据迁移
导出规则备份 (JSON)
将当前配置的所有域名与路径防护规则导出为 JSON 文件，用于多设备同步、版本备份或朋友共享。
导入规则备份 (JSON)
选择先前导出的 JSON 备份文件恢复规则。支持选择“合并导入”或“覆盖替换原有规则”。
清空所有防护规则
彻底清空本地存储中所有的防护规则。此操作无法撤销，建议在清空前先导出 JSON 备份。
🕶️ 免记录模式与默认策略
默认静默免记录时长
在弹窗快捷开启“静默免记录模式”时，预设的倒计时生效时长。到期后将由后台闹钟自动恢复常规防护。
快捷搜索词转规则策略
在历史大扫除中点击“删除并将搜索词加入永久隐藏”时，缺省的规则类型识别模式。
⚡ 海量历史检索性能与安全
单批次游标拉取条数 (Batch Size)
历史大扫除单次向底层 SQLite 请求的数据量。低配设备推荐 50 条以获得极致轻量内存，常规推荐 100 条。
批量删除并发分片大小 (Chunk Size)
并发调用底层删除 API 的分片步长。每完成一分片将自动让出主线程宏任务，彻底杜绝界面卡死。
流式全量清空前二次确认
针对十万级匹配结果点击“⚡ 流式全量清空”前，是否弹出系统警告对话框二次确认，防止误触误删。
